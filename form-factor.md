# Pokeshell form factor

## What it is

A gamified, collaborative workspace where a team shares the same codebase, session memory, running app, plans, prompts, and AI-assisted development activity and completes pokemon missions to win together as a team. The more a team plays, the more pokemons they capture Pokeshell hosts live team sessions with shared files and context, lets users run commands and edit code, tracks ownership and overlap, and connects execution to plans, tests, and deployment checks. Then in pokemon style, they capture pokemons, climb leaderboards and compete coding missions. Should have sample coding missions.
