- [ ] A team can share repository files during an active live session.

- [ ] A team can run commands during an active live session and inspect their recorded results when available.
- [ ] A team can inspect the running app state associated with active work.
- [ ] Shared context remains inspectable when activity has changed, failed, or is unavailable.
